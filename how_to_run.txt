
Expense Tracker Web App — Installation & Run Guide
==================================================

This guide will help you set up and run the Expense Tracker web application locally.

Prerequisites
-------------------
Make sure you have the following installed:

1. Python 3.8 or later: https://www.python.org/downloads/
2. pip (comes with Python)
3. Git (optional but helpful)

 Step-by-step Setup
----------------------

1. Clone or download the project folder.
   - If using Git:
     git clone <your-repo-url>

2. Open a terminal (or command prompt) inside the project folder.

3. [Optional but recommended] Create a virtual environment:
   Windows:
       python -m venv venv
       venv\Scripts\activate

4. Install all required packages:
   pip install -r requirements.txt

5. Set environment variables:
   (Skip this step if `.env` is already present or not needed)

   If you need to manually set environment variables, you can create a `.env` file:
   FLASK_APP=run.py
   FLASK_ENV=development

6. Run the application:
   flask run

7. Open your browser and visit:
   http://127.0.0.1:5000/
